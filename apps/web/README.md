# LeakShield web

React + Vite + Tailwind console: chat, incidents, overview, approvals and eval views. Owner: Arihant (see `docs/TEAM.md`).

```bash
npm install
npm run dev
```

The dev server runs on http://localhost:5173 and proxies `/api` and `/v1` to the gateway at `GATEWAY_URL` (default `http://localhost:8080`).
